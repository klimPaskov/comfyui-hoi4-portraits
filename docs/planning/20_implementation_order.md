# Implementation Order

## 1. Freeze inputs and topology

- read this package
- inspect Mac
- hash style LoRA
- resolve background
- establish access to target repositories
- select license review owner

Stop on a missing LoRA, unresolved background, or unsupported topology for a requested integration.

## 2. Initialize standalone project

Create layout, Git rules, schemas, manifest templates, controller skeleton, and test harness. Commit before installing large dependencies.

## 3. Pin ComfyUI and base environment

Install a test workspace, record ComfyUI and Manager versions, and verify server API routes. Do not install broad custom-node collections.

## 4. Implement deterministic intake

Build source preservation, decode, orientation, subject inventory, selection, crop, monochrome classifier, mask bundle, composite integrity, evidence saves, and unit tests.

## 5. Resolve preprocessing models

Qualify BiRefNet, DDColor, Real-ESRGAN, YuNet, SFace, and MediaPipe. Pin exact artifacts and licenses. Keep aggressive face restoration disabled.

## 6. Implement autoprompter sidecars

Qualify Qwen 4B local and Qwen 8B full power. Implement exact instruction, validator, unsupported-claim gate, bounded retry, and memory staging.

## 7. Qualify Krea 2 base and edit stack

Install pinned Krea models and `comfyui-krea2edit`. Reproduce the official example. Export actual node schemas. Test Turbo, identity adapter variants, sampler baseline, resolutions, and memory.

## 8. Qualify the user's style LoRA

Verify checksum and metadata. Test Turbo compatibility and trigger. Do not edit the LoRA.

## 9. Run architecture experiment

Execute the identity plus style matrix. Eliminate identity failures before style ranking. Lock selected route and profile defaults.

## 10. Generate four workflows

Build the typed graph specification, profile overlays, UI JSON, API JSON, visual groups, and manifests. Load all four without missing nodes.

## 11. Implement controller and project MCP

Implement job state machine, ComfyUI API client, progress, idempotency, cancellation, outputs, error contract, and local stdio MCP.

## 12. Calibrate independent audit

Build legal calibration set, choose thresholds, validate strata, implement randomized candidate order, and lock auditor identity.

## 13. Implement final PNG and DDS

Inspect live converter and vanilla precedent when available. Implement standalone converter, independent decoder, header tests, pixel round trip, and atomic success.

## 14. Run local Mac acceptance

Measure real memory, runtime, thermal behavior, output quality, recovery, and repeatability. Report infeasibility without relabeling remote work.

## 15. Build and test RunPod

Build container, attach persistent volume, use secrets, expose authenticated gateway, test clean deployment, cancellation, cost safeguards, and idle shutdown.

## 16. Produce integrations

Read live Chaos Redux and generic repositories. Apply or regenerate proposed files. Run repository validation. Create portable packages or draft pull requests.

## 17. Final audit and release

Run full acceptance, secret and weight scans, license review, checksum generation, documentation consistency, and release packaging.

## Parallel work

Safe parallel tracks after the project skeleton exists:

- source and background resolution
- preprocessing model qualification
- RunPod container design
- generic repository discovery
- audit calibration fixture preparation

Do not run generation architecture selection before Krea, style LoRA, and audit baseline are ready.
