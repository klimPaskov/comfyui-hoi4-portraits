# Identity/style experiment evidence

`identity_style_matrix.json` is the locked experiment design. It is a design
artifact, not a claim that the matrix has run. Runtime results belong under the
private `jobs/<job_id>/evidence/` tree and must record the exact model, node,
workflow, seed, calibration fixture, gate metrics, memory, and retry preset.

The matrix is selected by identity first. A style score cannot compensate for a
failed or uncertain identity, geometry, accessory, mask, or provenance gate.
